Memory hoeft niet altijd gespeeld te worden met plaatjes van dieren of huishoudelijke objecten. De werken van Gerd Arntz, de Nederlandse vormgever vooral bekend van zijn pictogrammen die we nog steeds in het dagelijks leven terugzien, doen ook prima dienst. De app is precies wat je verwacht - het standaard memory spel, met een timer om tegen te strijden. Een leuke, gratis manier om op interactieve wijze kennis te maken met Arntz zijn ontwerpen.
