Windows 7 verscheen oorspronkelijk in 2009, drie jaar na het bekritiseerde Windows Vista. Het was jarenlang het populairste besturingssysteem van Microsoft: zelfs het latere Windows 8 wist nooit de cijfers van zijn voorganger te evenaren. Dat lukte pas met [Windows 10](https://www.bright.nl/tags/onderwerpen/wetenschap/informatica/windows-10), dat sinds januari 2019 op meer apparaten geïnstalleerd staat dan Windows 7. Maar zelfs nu staat de al ruim tien jaar oude software op ongeveer een kwart van alle Windows-computers geïnstalleerd.

## Wat is er aan de hand?

Microsoft heeft de ondersteuning voor Windows 7 op 14 januari 2020 [officieel beëindigd](https://www.bright.nl/nieuws/artikel/4984821/windows-7-naar-10-gratis-upgrade-windows10-upgraden-win7). Het betekent dat er helemaal geen nieuwe updates voor het besturingssysteem zullen verschijnen. De huidige versie van Windows 7 is de laatste.

Jaren geleden verscheen voor het laatst een update met nieuwe functies voor Windows 7. Nu de ondersteuning officieel wordt gestaakt, komen er ook geen updates meer met veiligheidsupdates.

## Wat is het risico van een pc met Windows 7?

De veiligheidsupdates behoeden Windows-gebruikers tegen mogelijke cyberaanvallen. Als dankzij een onderzoek of na een hack een gat in Windows wordt gevonden, dicht Microsoft dat lek zo snel mogelijk met zo’n update, zodat niemand er misbruik van kan maken. Omdat dit bij Windows 7 niet langer gebeurt, word je in de toekomst dus vatbaar voor nieuw ontdekte hackmethodes, malware en andere cyberaanvallen.

Dat duurt nog wel even: op het moment van schrijven is de ondersteuning van Windows 7 nog maar net gestaakt en zijn computers nog vrij recent voorzien van veiligheidsupdates. De kans dat je nu vatbaar bent voor meerdere bekende beveiligingslekken is daarom nog vrij klein. Die kans groeit naarmate de tijd vordert.

## Mijn computer draait nog op Windows 7: wat nu?

Wie goed beschermd wil blijven, moet upgraden. Dat kan het beste naar Windows 10, dat door Microsoft wordt verkocht voor 140 euro in bijvoorbeeld de Microsoft Store.

Heb je een oude computer, dan is Windows 10 wellicht te zwaar voor je huidige apparatuur. In dat geval moet je de apparatuur in je computer vernieuwen, of zelfs een compleet nieuwe machine kopen.

Voor gebruikers die handig zijn met computers is er een legale manier om gratis te updaten naar Windows 10. [Lees er hier meer over](https://www.bright.nl/nieuws/artikel/4984821/windows-7-naar-10-gratis-upgrade-windows10-upgraden-win7).

## Zitten bedrijven met Windows 7 nu in de problemen?

Sommige bedrijven en overheidsinstanties gebruiken nog op grote schaal Windows 7. Updaten is voor hun niet zo voor de hand liggend, omdat ze soms software gebruiken die alleen goed op die Windows-versie werkt.

Voor die partijen maakt Microsoft een uitzondering. De ondersteuning voor Windows 7 wordt voor hun met maximaal drie jaar verlengd, mits ze betalen. Het eerste jaar kost dat 50 dollar (45 euro) per Windows 7-computer. In jaar twee gaat die prijs omhoog naar 100 dollar per computer, waarna er in het derde jaar 200 dollar per machine wordt betaald.

Na januari 2023 kunnen deze bedrijven niet meer op ondersteuning rekenen. Tenminste, dat zegt Microsoft nu: in de afgelopen jaren betaalde de Nederlandse overheid bijvoorbeeld forse bedragen aan Microsoft, om de ondersteuning voor oude Windows-versies nog iets meer te verlengen. Het is afwachten of in de toekomst vergelijkbare deals worden gesmeed.

## Ik heb Windows 8 of Windows 10, ben ik nog lang veilig?

Windows 8 wordt nog een paar jaar voorzien van veiligheidsupdates: pas na 10 januari 2023 wordt het besturingssysteem niet meer door Microsoft ondersteund.

Windows 10 zal nog tot 14 oktober 2025 updates ontvangen.
