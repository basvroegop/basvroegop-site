**Minder live-tegels**

> [!NOTE]
> Dit artikel verscheen eerder op [Bright](https://www.bright.nl/nieuws/1125619/microsoft-wil-windows-startmenu-weer-op-de-schop-nemen.html).

Dat vertelt een medewerker van Microsoft in de Windows Insider-podcast. Op het moment worden "de mogelijkheden verkend" voor een nieuw Windows 10-startmenu.

Vermoedelijk betreft het vooral een visuele update. Volgens Microsoft is het huidige menu wat chaotisch door alle kleuren van de live-tegels. Dit zijn de grote pictogrammen aan de rechterzijde, die soms zelfs bewegen. Bij een experiment wordt een uniforme kleuroptie onderzocht.

"We gaan de live-tegels niet schrappen", verzekert Brandon LeBlanc van het Windows Insider-team tegenover [The Verge](https://www.theverge.com/2020/3/3/21163687/microsoft-new-windows-10-start-menu-design-live-tiles-changes). "Iedereen die ze handig vindt kan ze gewoon blijven gebruiken."

## Windows 10X

Microsoft doet steeds minder met de tegels in het startmenu. In [Windows 10X](https://www.bright.nl/nieuws/artikel/4898986/beelden-van-windows-10x-op-surface-neo-gelekt), een besturingssysteem speciaal voor [apparaten met twee schermen](https://youtu.be/wLsionOOybQ), zijn ze bijvoorbeeld niet meer te vinden.

De techgigant probeert al jaren om het startmenu van Windows te verfijnen. De grootste stap was bij Windows 8, waarbij het subtiele menu van eerder werd verruild voor een groot en kleurrijk venster.
